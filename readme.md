# مستند متطلبات المنتج (PRD) - لعبة شد الحبل

## 1. المقدمة
هذا المستند يحدد متطلبات المنتج עבור لعبة شد الحبل التفاعلية التي تُلعب عبر المتصفح. اللعبة تجمع بين عناصر اللعبة البدنية (شد الحبل) والتحدي الذهني (حل أسئلة الرياضيات) لتشجيع التفاعل والتعليم بطريقة ممتعة.

## 2. الغاية من المشروع
الغاية من هذا المشروع هي توفير تجربة تعليمية ترفيهية تُعزز مهارات الحساب الذهني والتفاعل الاجتماعي البسيط (حتى لو كان عبر شاشة واحدة) من خلال لعبة شد الحبل التي تتطلب من اللاعبين حل أسئلة رياضية سريعة لتحريك الحبل لصالح فريقهم. تهدف اللعبة إلى:
- تحسين مهارات الجمع والطرح الذهني لدى اللاعبين.
- توفير وسيلة ترفيهية تعليمية مناسبة لجميع الأعمار.
- تشجيع المنافسة الودية بطريقة بصرية وتفاعلية.

## 3. الجمهور المستهدف
- الأطفال في سن المدرسة (من 6 إلى 12 سنة) لتمرن على العمليات الحسابية الأساسية.
- الكبار الذين يرغبون في تمرين عقل سريع وممتع.
- المعلمين والأهل كأداة تعليمية تكميلية.


## 4. الميزات
### الميزات الأساسية:
- dvouine teams (اليسار واليمين) تتنافس في شد الحبل.
- واجهة حساب بسيطة لكل فريق لإدخال إجابات أسئلة الرياضيات.
- إنشاء عشوائي لأسئلة الجمع والطرح مع أرقام مناسبة للمستوى التعليمي.
- تغذية راجعة فورية عند الإجابة (صحيح/خطأ) مع تأثيرات بصرية.
- حركة حبل متحركة reflejbar لتقدم كل فريق.
- نظام نقاط لتسجيل عدد الإجابات الصحيحة لكل فريق.
- إعلان الفائز عندما يصل الحبل إلى حدود الفوز المحددة.
- زر إعادة تعيين لبدء لعبة جديدة.

### الميزات التقنية:
- تصميم متجاوب (Responsive) ليعمل على مختلف أحجام الشاشات.
- دعم اللغة العربية بالكامل (اتجاه النص RTL).
- استخدام تقنيات ويب標準 (HTML5, CSS3, JavaScript Vanilla).
- لا يتطلب أي اعتماديات خارجية أو مكتبات إضافية.

## 5. واجهة المستخدم
تتكون واجهة اللعبة من:

- لوحة النتائج التي تظهر:
  - اسم الفريق (فريق اليسار / فريق اليمين)
  - النقاط الحالية لكل فريق
  - مؤشر منتصف الحبل النسبة المئوية لموقع الحبل
- منطقة اللعبة التي تضم:
  - تمثيل بصري لفريق اليسار (شخصيتين بأزياء حمراء)
  - تمثيل بصري لفريق اليمين (شخصيتين بأزياء زرقاء)
  - حبل في الوسط مع علامة مركزية ومؤشر نسبة
- قسمي الحاسبة (واحد لكل فريق) يحتويان على:
  - شاشة عرض للإدخال الحالي
  - عرض السؤال الرياضي الحالي
  - أزرار الأرقام (0-9)
  - زر مسح (C)
  - زر تغيير الإشارة (+/-)
  - زر إرسال الإجابة (✓)
- رسالة إعلان الفائز التي تظهر في نهاية اللعبة.
- زر إعادة التعيين (🔄 لعبة جديدة) يظهر بعد انتهاء اللعبة.

## 6. آلية اللعب
1. عند بدء اللعبة، يُعرض سؤال رياضي عشوائي لكل فريق (جمع أو طرح).
2. يدخل اللاعب الإجابة باستخدام أزرار الحاسبة الخاصة بفريقه.
3. عند الضغط على زر الإرسال:
   - إذا كانت الإجابة صحيحة:
     - يتحرك الحبل 4% نحو الفريق الذي أجاب بشكل صحيح.
     - يزيد نقطة الفريق بمقدار 1.
     - يُعرض سؤال جديد للفريق بعد تأخير قصير (300ms).
   - إذا كانت الإجابة خاطئة أو غير صالحة:
     - تظهر رسالة خطأ ويجب على اللاعب المحاولة مرة أخرى.
4. يستمر اللعب حتى يصل مؤشر الحبل إلى:
   - 15% أو أقل: فوز فريق اليسار.
   - 85% أو أكثر: فوز فريق اليمين.
5. عند الفوز، تُظهر رسالة الفائز وتعطل أزرار الحاسبة حتى يتم إعادة التعيين.
6. يمكن إعادة اللعبة في أي وقت بالضغط على زر إعادة التعيين، والذي يعيد 모든 المتغيرات إلى حالتها الابتدائية.

## 7. المتطلبات التقنية
- متصفح ويب حديث يدعم HTML5, CSS3, وJavaScript ES6.
- لا يتطلب خادم خلفي (يمكن تشغيله كموقع ستاتيكي).
- مساحة تخزين ضئيلة (ملفات HTML, CSS, JS فقط).
- لا يتطلب قاعدة بيانات أو أي اعتماديات خارجية.

## 8. الافتراضيات والاعتماديات
- يفترض أن اللاعبين يمتلكون القدرة على قراءة وفهم الأرقام والعمليات الأساسية.
- لا يتطلب اللعبة اتصالاً بالإنترنت بعد تحميل الصفحة الأولى (يمكن استخدامها دون اتصال).
- التصميم مبني على افتراض استخدام شاشة لمسية أو ماوس للتفاعل مع الأزرار.
- لا يتطلب اللعبة أي تسجيل دخول أو إنشاء حسابات.

## 9. التحسينات المستقبلية
- إضافة مستويات صعوبة مختلفة (مثل الضرب والقسمة).
- إمكانية تخصيص نطاق الأعداد والعمليات عبر إعدادات اللعبة.
- إضافة تأثيرات صوتية للإجابات الصحيحة والخاطئة وحركة الحبل.
- وضع لعب متعدد اللاعبين عبر الشبكة (مثلاً باستخدام WebSockets).
- إضافة سجل للنقاط والنتائج لتتبع التقدم عبر الجلسات المختلفة.
- دعم لغات متعددة oltre العربية.
- إضافة وضع مؤقت لتحدي السرعة.
- إمكانية تخصيص أشكال الفرق والخلفيات.
